# verbose-guacamole
Kalman Filters and C++Review

To build cpp project using CMake:
ensure Cmake is installed: cmake --version
Run `cmake -S . -B build` from the /cpp dir
Run `cmake --build build`
Run ` .\build\Debug\<executatble_name>.exe` where the executable name is found in the CMake file

to use a compiler, use `g++ <source files...> -o <executable>`, then run using `./executable`
